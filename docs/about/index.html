關於我

我是顏和平，長照機構營運與評鑑顧問、社工教師，目前就讀東海大學社會工作學系博士班。

我是從第一線走進來的。做過照顧服務員，當過日照與身障日照的社工，後來轉任督導與主任。這一路看到太多機構不是不努力，而是缺少一套系統化的方法——同樣的錯誤在不同機構重複發生，同樣的流程每次都要從頭摸索。走過那些冤枉路之後，我決定往研究、教學與顧問的方向投入，把散落在各處的實務經驗整理成可以被檢驗、被複製的東西。

我相信長照不只靠經驗，更需要把實務整理成可複製、可傳承的方法。經驗會隨著人離職而流失，方法不會。

我的使命，是把長照實務轉化為可以傳承的知識； 讓機構少走冤枉路，讓照顧回歸專業。

好的管理，是成就一個團隊

擔任日間照顧中心主任期間，我帶領團隊榮獲包大人長照摘星之旅全國第一名，並培育兩位照顧服務員分別獲得臺中市金照獎－長照新星獎第二名及第三名。

對我而言，這些成果的價值，不只是獎項本身，而是代表一套好的制度、好的領導與好的團隊文化，能夠讓第一線工作者持續成長，也讓長照服務品質被更多人看見。

我的長照旅程

從第一線實務到建立可傳承的 know-how。

  1. 01

    第一線照顧

    照顧服務員

    從最貼近長輩的工作開始，理解照顧真正的難處。

  2. 02

    社工專業

    日照中心 / 身障日照社工

    處理個案評估、家屬溝通與跨專業協作。

  3. 03

    機構經營管理

    督導 / 主任

    開始面對人力、法規、成本與品質的整體平衡。

  4. 04

    持續精進

    雙碩士 / 東海社工博士班

    補上研究方法邏輯，解構與重新結構現場的實務工作。

  5. 05

    知識傳承

    顧問 / 講師

    把現場經驗整理成可複製、可傳承的方法。

專業定位

  • 橫跨居家、日照、住宿三種模式

    三種服務型態的法規、人力配置與流程設計都不同。能對照著談，才知道哪些做法可以移植。

  • 實務、管理與研究兼具

    現場經驗負責服務模式的執行方法，管理視角負責行政經營管理、照顧品質監測、團隊建置運作、空間環境規劃、建構資源網絡等，研究方法負責拆解與重組繁瑣複雜的工作任務。

  • 持續擔任顧問與教學

    把機構遇到的真實問題帶回課堂拆解，再把方法帶回現場驗證。
