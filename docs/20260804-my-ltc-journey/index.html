我的長照，從第一線開始

我的長照，不是從辦公室開始

很多人認識現在的我，是長照機構顧問、講師，或正在攻讀博士班。

但其實，我的長照旅程，不是從研究室開始，也不是從管理職開始。而是從第一線照顧服務員開始。

我曾經在住宿型長照機構擔任照顧服務員，每天協助長輩起床、沐浴、更衣、進食、移位，也陪伴他們度過生命中許多重要的時刻。

那些經驗，不只是工作，更是我理解長照的起點。

我一直相信

好的管理，不是坐在辦公室想出來的。 而是來自真正理解第一線工作的困難。

因為曾經做過照服員，所以我知道：

  • 一份 SOP 是否真的做得到？
  • 一張紀錄表是否只是增加工作負擔？
  • 一項制度究竟是在幫助照顧，還是在增加困擾？

這些問題，只有真正站在第一線的人，才能理解。

後來，我開始走向不同的角色

從照顧服務員開始，我陸續擔任：

  • 日間照顧中心照顧服務員
  • 居家長照機構副督導
  • 日間照顧中心社工師
  • 身心障礙日照中心社工師
  • 日間照顧中心主任

一路走來，我橫跨了住宿式、社區式、居家式三種長照服務模式。

也因為如此，我開始發現一個共同的問題。

長照最大的問題，不是沒有努力

而是沒有一套大家都能依循的方法。

有些機構做得很好，卻不知道為什麼成功；有些主管非常努力，卻每天都在救火；更多的是，每到評鑑前，整個團隊開始加班整理資料。

我曾經歷過，也陪伴許多機構經歷過。

所以我開始思考：能不能把這些經驗，整理成一套可以學習、可以複製的方法？

這也是我持續研究的原因

後來，我完成了長照相關碩士，也完成非營利組織經營管理碩士，目前持續攻讀東海大學社工博士班。

不是因為我想多一張文憑。而是我希望把多年累積的實務經驗，轉化成可以傳承的知識。

我希望未來的長照工作者，不需要再走我們走過的冤枉路。

這也是這個網站存在的原因

這裡，不只是分享長照資訊。我更想分享的是：

  • 長照機構營運
  • 品質管理
  • 評鑑制度
  • 第一線管理
  • 團隊領導
  • SOP 建立
  • 我在顧問工作中的觀察與思考

因為我相信：

真正的長照品質，不是評鑑前兩個月建立的，而是每天累積出來的。

最後，我想說

我希望這個網站，不只是紀錄我的工作。更希望它成為一個地方——讓長照工作者、主管、經營者，都能找到一套真正來自實務、也能真正落實在現場的方法。

讓長照，不只靠經驗，更靠方法。
